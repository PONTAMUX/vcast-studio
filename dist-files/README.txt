VCast Studio（仮称）
====================
3Dアバター配信に特化した、軽量な配信ソフトです。

■ 起動
  VCastStudio.exe をダブルクリック。インストールは不要です（フォルダごと好きな場所に置けます）。
  Windows 10/11（64bit）。映像の圧縮に GPU（NVIDIA / AMD / Intel）を使います。

■ はじめに（かんたんモード）
  画面の右に ①〜④ のカードが並んでいます。上から順に進めれば配信できます。
  ① アバター  「VRM ファイルを選ぶ…」でモデル（.vrm）を選ぶ。配信画面に自動で出ます
  ② マイク    マイクに話して、緑のバーが動けば OK
  ③ 配信先    「配信設定」で YouTube / Twitch のストリームキーを入れる
  ④ 映すもの  ゲーム画面・画面全体・カメラ・画像などを追加する
  そのあと上の「● 配信開始」。開始の前に、マイクや音割れなどを自動でチェックします。
  右上「？ 使い方」に、操作方法と各機能の説明があります。

■ 上級者向け（プロモード）
  上の「🔧 プロモードへ」で、シーンを細かく組む・スタジオモード（プレビューと本番）・音声ミキサー・
  サウンドボード・ホットキー・プロファイル（番組ごとの設定）などが使えます。

■ 設定・ログの場所
  %APPDATA%\VCastStudio\   （設定、シーン、ログ。ストリームキーは Windows のユーザーごとの暗号化で保存されます）
  ソフトを消したいときは、このフォルダと VCast のフォルダを削除してください。

■ Windows が「PC を保護しました」と出るとき
  このソフトはコード署名をしていません。「詳細情報」→「実行」で起動できます。

■ 外部から操作（Stream Deck など）
  「⚙ 配信設定」の「外部から操作」をオンにすると、OBS 用のリモコン（obs-websocket v5 対応）から操作できます。
  パスワードが必須です。ほかの機器からの接続を許可すると、同じネットワークの人が（パスワードを知っていれば）
  操作できます。通信は暗号化されないので、信頼できるネットワークの中だけで使ってください。
