# VCast Studio（仮称）企画たたき台 v0

## ユーザー要望（原文要約）
- VTuber向け、**3Dモデル配信に特化**した配信ソフト
- 企業利用も想定 → 配信設定の詳細機能を豊富に
- **かんたんモード / 詳細（オペレーター）モード**を分ける。vMix のようなオペレーション
- **軽量**を目指す
- **OBSのプラグインが使える**
- 動画ファイル・音声ファイルを直接流せる（プレイリスト）
- 疑似サウンドボード

## 開発環境の事実
- Windows 11 / RTX 3070 / .NET 8 SDK あり / Node あり / Python あり / ffmpeg あり
- **Visual Studio・CMake・Rust は無し**（C++ビルド環境なし。MinGW g++ はある可能性）
- OBS Studio 32.1.2 インストール済み（obs.dll と obs-plugins/64bit 一式あり、obs-browser(CEF) / obs-nvenc / win-capture / obs-vst / obs-websocket 等）
- 予算ゼロ（有料SDK・有料サービス不可）

## 技術方針の候補
### A. libobs（obs.dll）を自前フロントエンドから直接使う ← 本命
- OBS本体のエンジン(libobs)は C API。**C#/.NET 8 から P/Invoke** で呼べる → C++ビルド環境不要
- エンジンがOBSそのものなので: GPU合成・NVENC/QSV/AMF・RTMP/SRT/WHIP・録画・リプレイバッファが最初から高品質
- **OBSのソース/フィルタ/出力系プラグイン(.dll)はそのまま読み込める**（obs_load_all_modules）
- ただし `obs-frontend-api`（OBSのQt UIに依存するドック系プラグイン、obs-websocket 等）は互換レイヤーを自作しないと動かない
- UI: WPF（軽い・ネイティブ） or WebView2(HTML) or Avalonia
- ライセンス: libobs は GPL-2.0 → 配布するなら本アプリも GPL（有償販売は可だがソース公開義務。企業向けはサポート/導入支援で稼ぐモデル）
- 3Dアバター: 当面は obs-browser（CEF）ソースで three-vrm + MediaPipe 顔トラッキングのページを描画（OBSプラグイン流用、実装が速い）。将来ネイティブ描画ソース化
- VMC Protocol 受信にも対応（既存トラッカー VSeeFace / Webcam Motion Capture / iFacialMocap 等を使える）

### B. Electron / Tauri + three.js + ffmpeg を自作
- 実装は楽だがOBSプラグイン非対応、エンコード品質・安定性をゼロから作る。軽量要件にも反する → 非推奨

## 機能案
### 必須（ユーザー要望）
- シーン / ソース（カメラ・画面・ウィンドウ・ゲーム・画像・テキスト・ブラウザ・メディア）
- 3Dアバター（VRM 0.x/1.0）: Webカメラ顔トラッキング、口パク（音声リップシンク）、まばたき、表情ホットキー
- かんたんモード: 「アバター選ぶ→マイク選ぶ→配信先選ぶ→配信開始」の1画面
- プロモード（vMix風）: Preview / Program 2画面、トランジションバー(T-bar)、カット/オート、入力一覧サムネ、オーディオミキサー、マルチビュー
- 配信設定詳細: エンコーダ選択・CBR/VBR/CQP・キーフレーム・プロファイル、**マルチ配信（YouTube/Twitch/X同時）**、録画同時、SRT/WHIP
- メディアプレイリスト（動画/音声、ループ・次へ・フェード）
- サウンドボード（パッド＋ホットキー、音量個別、ダッキング）
- OBSプラグイン読込

### 追加提案（配信で便利な機能）
- リプレイバッファ（直前30秒を保存）／インスタントリプレイ
- 縦型同時出力（ショート/TikTok用の9:16キャンバスを同時に）
- マイク音声処理: ノイズ抑制(RNNoise/NVIDIA)、コンプレッサー、ゲート、リミッター、VSTプラグイン
- 自動ダッキング（喋るとBGMが下がる）
- ボイスチェンジャー（VST経由）
- コメント読み込み・オーバーレイ、コメント読み上げ
- ホットキー / Stream Deck / MIDIコントローラ対応
- 配信ヘルスモニタ（ドロップフレーム・ビットレート・CPU/GPU）
- シーンコレクション・プロファイル（企業: 番組ごと切替）
- タリーライト / NDI 入出力（企業）
- 遅延配信（放送事故対策のディレイ）
- 仮想カメラ出力（Zoom/Teams へアバター出し）
- 字幕（音声認識 → テロップ）
- 配信前チェックリスト（マイクミュート確認・音量ピーク）
- アバター物理（揺れもの）、背景透過、アバターへのアイテム投げ（視聴者連動）

## 相談したいこと
